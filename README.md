# React Pizza App 🍕

![React Pizza App](/react-pizza-app.png)

React Pizza App is a vibrant, interactive menu application designed for a fictional pizzeria. This project served as my formal introduction to the React.js ecosystem, focusing on the fundamental principles of component based architecture and dynamic data rendering.

**[Live Preview](https://yuzstack-react-pizza-app.netlify.app/)**

## 🛠️ Technical Stack

- **Frontend Library:** React.js
- **Styling:** Vanilla CSS

## 🧠 Development Overview

As the first project in my React curriculum, this application was built with a focus on foundational mastery. By following a structured development process, I gained my first hands-on experience with how React manages the User Interface through components and how data flows from parent to child via props.

## ✨ Key Features

- **Component Based Architecture:** Developed a modular structure where each pizza item is its own reusable component.
- **Dynamic Content Rendering:** Implemented logic to render a full menu from a centralized data array, ensuring the UI stays in sync with the underlying information.
- **Conditional Styling:** Built logic to visually handle "Sold Out" states, dynamically updating the CSS and button availability based on item status.
- **Interactive UI Elements:** Created a clean, responsive header and footer that utilize JavaScript logic to display store hours and current availability.
- **Foundational Prop Drilling:** Mastered the basics of passing data down through the component tree to build a cohesive and interactive experience.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository: `git clone https://github.com/YuzStack/49_Pizza-App.git`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
